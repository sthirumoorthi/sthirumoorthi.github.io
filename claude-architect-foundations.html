01

Agentic Architecture & Orchestration

27%

Design and implement agentic systems using Claude’s API, including loop management, orchestration patterns, guardrails, and the Claude Agent SDK.

Lesson map

1.1 Agentic LoopsStudy noteUse stop_reason as the deterministic loop signal: continue on tool_use and finish on end_turn. Append tool results to the conversation before the next request.
1.2 Multi-Agent OrchestrationStudy noteUse hub-and-spoke coordination for the exam: the coordinator decomposes work, routes context, aggregates results, and keeps subagents from communicating directly.
1.3 Subagent Invocation & Context PassingStudy noteGive the coordinator Task/Agent permission, pass context explicitly, and preserve structured metadata such as source URLs and document names.
1.4 Workflow Enforcement & HandoffStudy noteUse programmatic gates for money, security, and compliance; prompts are probabilistic, while prerequisite checks and hooks are deterministic.
1.5 Agent SDK HooksStudy noteUse PreToolUse to block or rewrite a call before execution and PostToolUse to normalise results after execution.
1.6 Task Decomposition StrategiesStudy noteMatch fixed sequential pipelines to predictable work and dynamic decomposition to open-ended investigation; watch for narrow decomposition and attention dilution.
1.7 Session State & ResumptionStudy noteResume when context is still valid, fork for a divergent approach, and start fresh with a structured summary when the old context is stale.

Tool Design & MCP Integration

18%

Design effective tool schemas, implement MCP servers and clients, and integrate external services into Claude-powered applications.

Lesson map

2.1 Tool Interface DesignStudy noteDescriptions should state purpose, inputs, examples, edge cases, and boundaries. Sharpen descriptions before adding a routing layer.
2.2 Structured Error ResponsesStudy noteReturn structured errorCategory, isRetryable, and description metadata. Separate access failures from valid empty results; retry transient failures, not business or permission failures.
2.3 Tool Distribution & Tool ChoiceStudy noteKeep agents near four or five role-specific tools, consolidate same-shaped operations, and use auto, any, or forced tool selection for the right guarantee.
2.4 MCP Server IntegrationStudy noteUse project .mcp.json for shared configuration, user-level settings for personal connections, environment variables for secrets, and community servers for standard integrations.
2.5 Built-in ToolsStudy noteRemember the Claude Code tools: Read, Write, Edit, Bash, Grep, and Glob. Grep searches file contents; Glob matches file paths.

04

Prompt Engineering & Structured Output

20%

Craft effective prompts, implement structured output patterns, and apply production prompt-engineering techniques.

Lesson map

4.1 System Prompts with Explicit CriteriaStudy noteReplace vague confidence language with explicit categories, boundaries, and concrete examples; temporarily disable high-false-positive categories while refining them.
4.2 Few-Shot PromptingStudy noteUse representative input/output examples when detailed instructions still produce inconsistent formats, judgements, or extraction fields.
4.3 Structured Output with Tool UseStudy noteSchemas prevent syntax errors but not semantic errors. Use nullable fields for genuinely missing data and tool_choice any when a tool call is required.
4.4 Validation, Retry & Feedback LoopsStudy noteRetry with the original source, failed output, and specific validation error; do not retry when the source cannot contain the missing information.
4.5 Batch Processing StrategiesStudy noteRefine prompts on a representative sample before batch submission. Batch is cost-efficient but latency-tolerant; tool loops remain synchronous.
4.6 Multi-Instance & Multi-Pass ReviewStudy noteUse independent review instances, per-file passes, integration review, and calibrated confidence routing instead of trusting the generator to review itself.

05

Context Management & Reliability

15%

Manage context windows effectively, implement caching strategies, handle long conversations, and build reliable production systems.

Lesson map

5.1 Context Window ManagementStudy noteProtect transactional facts in a persistent case-facts block, put key findings first, trim tool results, and place stable prefixes before cache breakpoints.
5.2 Escalation & Ambiguity ResolutionStudy noteEscalate on an explicit human request, a policy gap, or inability to progress; do not use sentiment or raw self-reported confidence as the trigger.
5.3 Error Propagation in Multi-Agent SystemsStudy noteRecover transient failures locally, propagate structured failure context and partial results, and never hide a timeout as an empty success.
5.4 Codebase Exploration & Context DegradationStudy noteExplore incrementally, delegate verbose discovery to isolate context, and persist key findings in scratchpads or crash-recovery manifests.
5.5 Human Review & Confidence CalibrationStudy noteMeasure accuracy by document type and field segment, calibrate confidence on labelled data, and use stratified sampling before reducing human review.
5.6 Information Provenance & Multi-Source SynthesisStudy notePreserve claim, source URL, document, excerpt, and date. Annotate conflicts instead of selecting a value arbitrarily.
